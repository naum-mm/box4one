# BOX4ONE

Веб-интерфейс и Telegram-бот для **yt-dlp**: видео 480p/720p/1080p, аудио MP3,
плейлисты, общая очередь, потоковый ZIP и автоматическая очистка результатов.
Веб-админка показывает полную историю; Telegram — последние 10 заданий пользователя.
Все лимиты, пароли и настройки Telegram находятся в одном `.env`.

## Требования

Ubuntu 24.04 LTS (amd64/arm64), root/sudo, `curl`, домен и открытые TCP 80/443.
Рекомендуется от 2 ГБ RAM и 20 ГБ диска. Для сервера с 1 ГБ RAM нужен настроенный
swap от 2 ГБ; сборка и обработка будут медленнее. Установщик swap не создаёт.
Для задания нужен свободный диск с учётом `MAX_JOB_GB`, резерва `MIN_FREE_GB`,
других результатов и места для сборки/резервных копий. Shared hosting без Docker
не подходит. Docker при необходимости устанавливается автоматически.

## Один скрипт для установки и обслуживания

Скачайте актуальный скрипт с GitHub и запустите нужное действие:

```bash
curl -fsSL https://raw.githubusercontent.com/naum-mm/box4one/main/bootstrap.sh -o /tmp/box4one.sh
sudo bash /tmp/box4one.sh install video.example.com
```

Замените домен своим. Проект устанавливается в `/opt/ytdlp-web`; существующий
каталог установка не перезаписывает. Секреты создаются автоматически и не печатаются.
Пароли доступа: `DOWNLOAD_ACCESS_WORD` и `QUEUE_ACCESS_WORD` в `.env`.

Тем же скриптом (перед обслуживанием скачайте его заново):

| Действие | Команда |
|---|---|
| Обновить, сохранив настройки, историю и файлы | `sudo bash /tmp/box4one.sh update` |
| Сохранить настройки и историю | `sudo bash /tmp/box4one.sh backup` |
| Добавить скачанные файлы в архив | `sudo bash /tmp/box4one.sh backup --include-files` |
| Остановить с сохранением всех данных | `sudo bash /tmp/box4one.sh uninstall` |
| Полностью удалить, предварительно сохранив настройки и историю | `sudo bash /tmp/box4one.sh uninstall --purge` |
| Восстановить в отсутствующий каталог проекта | `sudo bash /tmp/box4one.sh restore /var/backups/box4one/ARCHIVE.tar.gz` |

Обновление и полное удаление сначала создают проверенный архив вне проекта,
в `/var/backups/box4one` (доступ только root). Если резервная копия не получилась,
удаление не выполняется. Полное удаление требует ввода `DELETE`.
Обычный архив содержит конфигурацию и всю БД, включая историю веба/Telegram;
скачанные файлы включаются только с `--include-files`. Копию архива храните также
вне сервера. Активные загрузки нужно завершить перед обновлением; на время
обновления приложение останавливается. При ошибке автоматического отката БД нет.

## HTTPS и Telegram

После настройки DNS установите Certbot и выполните:

```bash
sudo apt update && sudo apt install -y snapd
sudo snap install --classic certbot
cd /opt/ytdlp-web
sudo ./enable-https.sh
```

Для Telegram заполните параметры в `.env` и задайте `COMPOSE_PROFILES=telegram`,
затем запустите `update` единым скриптом. Миграция общей БД выполняется автоматически
до запуска бота. Не запускайте несколько копий бота с одним токеном.

- [Установка, обновление, восстановление и настройки](docs/SETUP.md)
- [Telegram: команды, ограничения и выдача файлов](docs/TELEGRAM.md)
- [Остановка и полное удаление](docs/UNINSTALL.md)
- [Диагностика и ошибки заданий](scripts/README.md)
- [Все переменные единого .env](.env.example)

Проект использует yt-dlp, Node.js, FFmpeg и браузерный транспорт curl_cffi через
защитный прокси. Доступность источников зависит от возможностей yt-dlp и сети.
Рабочие настройки, база, сертификаты и пользовательские файлы в Git не входят.

## Telegram Local API и публичная активация

Бот открывается любому пользователю; доступ к заданиям открывает кодовое слово из
`TELEGRAM_ACTIVATION_WORD` (начальное значение `REDACTED_ACTIVATION_WORD`). Активация и лимит попыток
хранятся в MariaDB; прежний allowlist больше не обязателен.

Опциональный официальный Local Bot API позволяет передавать файлы до 2000 MB по
локальному пути. Без его credentials бот продолжает работать через облако с лимитом
49 MB и защищёнными HTTPS-ссылками. Полная [инструкция по настройке,
переключению, проверке ресурсов и откату](docs/TELEGRAM-LOCAL-API.md).
