# Удаление BOX4ONE

Команды выполняются на сервере установки. Перед полным удалением сохраните нужные загрузки из `/opt/ytdlp-web/jobs` и резервную копию данных. Автоматическую резервную копию скрипт не создаёт.

## Остановить и сохранить данные

```bash
cd /opt/ytdlp-web
sudo ./uninstall.sh
```

Удаляются контейнеры проекта и его Compose-сеть. Удаляется только hook продления Nginx, который указывает на этот каталог. Исходники, `.env`, база и загрузки остаются на диске. Сервис перестаёт отвечать.

Возобновить:

```bash
cd /opt/ytdlp-web
sudo docker compose up -d
# Если использовался HTTPS, восстановить hook и проверить продление:
sudo ./enable-https.sh
```

## Полностью удалить проект и его данные

```bash
cd /opt/ytdlp-web
sudo ./uninstall.sh --purge
```

Введите `DELETE`. После остановки контейнеров удаляется весь каталог проекта, включая `.git`, `.env`, базу задач, файлы и логи, хранящиеся в этом каталоге. Отмена ввода ничего не удаляет.

Для автоматизации, без интерактивного подтверждения:

```bash
sudo /opt/ytdlp-web/uninstall.sh --purge --yes
```

Это необратимое удаление данных проекта. Скрипт проверяет маркер `.box4one-install` и принадлежность контейнеров текущему каталогу. Если проект вручную перемещён или маркер отсутствует, он остановится: сначала проверьте путь и Docker labels. Скрипт предназначен для установки из этого репозитория, а не для старой установки без маркера.

## Что остаётся

Docker Engine, скачанные Docker-образы, Certbot и сертификаты сохраняются: ими могут пользоваться другие приложения. Скрипт не очищает чужие контейнеры, не выполняет `docker system prune`, не меняет firewall/DNS и не удаляет системные пакеты.

Если сертификат этого домена больше нигде не нужен, удалить его средствами Certbot:

```bash
sudo certbot certificates
sudo certbot delete --cert-name video.example.com
```

Если команда `certbot` отсутствует в PATH, используйте `/snap/bin/certbot`. Замените домен своим. Удаление сертификата прекратит его дальнейшее продление. Не удаляйте файлы вручную из `/etc/letsencrypt`.
