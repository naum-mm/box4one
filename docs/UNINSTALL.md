# Удаление BOX4ONE с сохранением данных

Скачайте единый скрипт управления:

```bash
curl -fsSL https://raw.githubusercontent.com/naum-mm/box4one/main/bootstrap.sh -o /tmp/box4one.sh
```

## Остановить и оставить все данные на месте

```bash
sudo bash /tmp/box4one.sh uninstall
```

Контейнеры проекта и его внутренняя сеть удаляются. Исходники, единая `.env`,
база с полной историей, результаты и hook сертификатов остаются в проекте.
Возобновление: `cd /opt/ytdlp-web && sudo docker compose up -d --wait`.
Остановка может прервать активные задания; дождитесь их завершения заранее.

## Полностью удалить установку, сохранить конфигурацию и историю в архиве

```bash
sudo bash /tmp/box4one.sh uninstall --purge
```

Введите `DELETE`. До удаления скрипт останавливает приложение, оставляет БД
для создания SQL-дампа и сохраняет проверенный архив вне проекта:
`/var/backups/box4one/box4one-*.tar.gz` (0600). Архив содержит `.env`, Nginx и всю
историю веба/Telegram. Если дамп или проверка архива не удались, каталог не удаляется,
прежние работающие сервисы запускаются обратно. БД должна быть доступна.
Затем удаляются контейнеры, внутренняя сеть, принадлежащий установке hook и весь
каталог `/opt/ytdlp-web`, включая исходники, базу, секреты и скачанные результаты.

Чтобы сохранить также скачанные файлы:

```bash
sudo bash /tmp/box4one.sh uninstall --purge --include-files
```

Без `--include-files` скачанные результаты удаляются безвозвратно; записи истории
остаются в архиве. Учтите размер файлов и свободное место для создания архива.
Для автоматизации `--yes` заменяет ввод `DELETE`, но не отключает резервную копию.
Архивы не удаляются автоматически; переносите их на отдельный носитель и храните
как секреты. Полное удаление относится к проекту, а не ко всему серверу.

Локальный `sudo /opt/ytdlp-web/uninstall.sh` принимает те же параметры.
Проверяются маркер пути и принадлежность контейнеров. При перемещённой установке
или отсутствии маркера скрипт останавливается, ничего не удаляя.

## Восстановление

После полного удаления используйте тот же скачанный скрипт:

```bash
sudo bash /tmp/box4one.sh restore /var/backups/box4one/ARCHIVE.tar.gz
```

Каталог проекта должен отсутствовать. Восстановление сохраняет секреты, историю
и состояние Telegram из архива. Готовые файлы возвращаются только если они были
включены в архив; TTL и сроки подписанных ссылок не продлеваются.
[Подробности восстановления и HTTPS](SETUP.md).

Docker Engine, образы, Certbot, `/etc/letsencrypt`, внешние сети и чужие проекты
остаются: они могут использоваться совместно. Глобальная очистка Docker и удаление
системных пакетов не выполняются. Сертификат, который больше нигде не используется,
можно отдельно удалить командой `sudo certbot delete --cert-name video.example.com`.
