# Telegram и веб в одной установке BOX4ONE

Бот и сайт используют один backend, одну MariaDB, общую таблицу jobs, один worker
и каталог результатов. Telegram работает в личных чатах через long polling.
Отдельной работающей тестовой установки для бота не требуется.

## Единая конфигурация

Все значения проекта задаются в корневом `.env` с правами 0600. Образец всех
переменных — [`.env.example`](../.env.example). Не создавайте worker/config.env,
cleanup/config.env, telegram-bot.env, telegram-integration.env или Compose override
для настройки приложения. Compose передаёт каждому сервису только нужные ему
значения: бот не получает пароли MariaDB и WORKER_API_TOKEN.

Пароли сайта и текущие секреты при обновлении сохраняются. Никогда не добавляйте
настоящий `.env`, токен бота или резервные копии с секретами в Git.

| Переменная | Значение по умолчанию и назначение |
|---|---|
| `COMPOSE_PROFILES` | Пусто — бот отключён; `telegram` — включён |
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `TELEGRAM_INTERNAL_TOKEN` | Отдельный случайный секрет, не менее 32 символов |
| `TELEGRAM_ALLOWED_USERS` | Числовые Telegram ID через запятую |
| `TELEGRAM_API_URL` | `http://backend:8000`, внутренний адрес backend |
| `TELEGRAM_PUBLIC_URL` | Пусто — `https://DOMAIN`; HTTPS-адрес выдачи файлов |
| `TELEGRAM_MAX_ACTIVE_JOBS` | `2`, активных заданий на пользователя |
| `TELEGRAM_HISTORY_LIMIT` | `10`, последних заданий в `/myjobs`, диапазон 1–100 |
| `TELEGRAM_POLL_SECONDS` | `10`, интервал обновления уведомлений |
| `TELEGRAM_UPLOAD_LIMIT_BYTES` | `49000000`, прямой upload; максимум 49 МБ |
| `TELEGRAM_LINK_TTL_SECONDS` | `600`, срок подписанной ссылки |
| `TELEGRAM_DRAFT_TTL_MINUTES` | `60`, срок выбора формата после ссылки |
| `TELEGRAM_MAX_DRAFTS_PER_HOUR` | `60`, ограничение количества новых ссылок |
| `TELEGRAM_CHAT_INTERVAL_SECONDS` | `1.1`, минимальная пауза между отправками в чат |
| `TELEGRAM_SEND_INTERVAL_SECONDS` | `0.06`, минимальная глобальная пауза отправки |
| `JOB_TTL_MINUTES` | `30`, срок хранения после завершения задания |
| `MAX_JOB_GB` | `2` ГиБ на задание, включая временные файлы |
| `MIN_FREE_GB` | `2` ГиБ свободного места, резерв диска |
| `VIDEO_PLAYLIST_LIMIT` / `AUDIO_PLAYLIST_LIMIT` | `50` / `100` элементов |
| `ARCHIVE_MAX_CONCURRENT` | `1`, одновременно создаваемых ZIP |
| `CLEANUP_INTERVAL_SECONDS` | `60`, период удаления истёкших файлов |

В `.env` также находятся настройки БД, ресурсы контейнеров, журналов и сетей.
`EGRESS_NETWORK_NAME` и `EGRESS_NETWORK_EXTERNAL=true` позволяют сохранить
существующую внешнюю сеть при обновлении установки с другими сайтами.
Внутренняя сеть не должна быть внешней: backend, БД и worker остаются в ней;
Nginx, бот и проверяющий загрузки прокси получают также egress.

Справка `/help` и `/start` формируется из тех же значений `.env`: размер задания,
плейлисты, параллельные задания, прямой upload, срок хранения и срок ссылки.
После изменения `.env` пересоздайте затронутые сервисы через `docker compose up -d`;
обычный `restart` не перечитывает окружение контейнера.

## Включение

1. Создайте обычного бота через BotFather; запишите его токен и разрешённые ID в `.env`.
2. Задайте отдельный `TELEGRAM_INTERNAL_TOKEN` и `COMPOSE_PROFILES=telegram`.
3. Сделайте резервную копию рабочей БД и конфигурации.
4. Проверьте настройки, соберите образы и выполните additive миграцию:

```bash
python3 scripts/configure.py check
docker compose config --quiet
docker compose build
docker compose run --rm --no-deps backend python -m app.telegram_migrate
docker compose up -d --wait
```

Миграция создаёт telegram_users, telegram_requests и telegram_runtime и не заменяет
jobs/files. Её выполняет один оператор, явно, до запуска бота. Startup backend
не выполняет Telegram-миграцию автоматически. Домен и HTTPS должны быть настроены.
При обновлении дождитесь завершения активных заданий перед пересозданием worker.

## Общая очередь и доступ

`/status` показывает последнее задание пользователя; `/myjobs` — последние
`TELEGRAM_HISTORY_LIMIT` его заданий. Уведомления о более старых незавершённых
заданиях продолжают приходить. Ограничение истории не удаляет записи из БД и
не ограничивает число заданий общей очереди.

Веб-админка сохраняет полную историю с пагинацией по 25 заданий. Случайный код
задания открывается через обычный веб-интерфейс независимо от источника задания;
доступ к списку очереди требует пароль очереди. Telegram API проверяет владельца
и allowlist; Telegram ID не выдаётся через веб-API.

Для одного токена запускайте ровно один polling-процесс. Cursor, дедупликация,
черновики, lease и состояния уведомлений хранятся в общей MariaDB.

## Выдача файлов

MP4 отправляется как видео с размерами и поворотом из MP4; MP3/M4A — как аудио.
Остальные форматы отправляются документом. Файлы передаются блоками по 64 КиБ,
без загрузки целиком в память. Более крупные файлы и ZIP доступны по подписанной
HTTPS-ссылке. Подпись ограничена сроком ссылки и сроком хранения задания;
получатель может переслать ссылку до истечения срока.

Истечение TTL блокирует дальнейшее скачивание с BOX4ONE; копия, уже отправленная
в Telegram, остаётся в Telegram. Backend проверяет TTL при каждом запросе.
Nginx не публикует `/api/integrations/telegram`; для подписанных ссылок отключены
логи и буферизация. Worker загружает через proxy с проверкой публичного назначения,
а FFmpeg/ffprobe работают с локальными протоколами.

Официальные ограничения: [Telegram Bot API](https://core.telegram.org/bots/api#sendvideo).
Используется обычный облачный Bot API, без отдельного локального Bot API Server.

## Обслуживание

```bash
docker compose ps
./scripts/diagnose.sh
./scripts/logs.sh telegram-bot -f
docker compose stop telegram-bot
```

Для отключения уберите `telegram` из `COMPOSE_PROFILES` и остановите бот. Основные
сервисы продолжают работать; дополнительные таблицы и история сохраняются.
При откате остановите бот, верните сохранённые образы и конфигурацию; не заменяйте
БД старым дампом поверх новых заданий. Тесты запускаются с синтетической отдельной
БД только на время проверки, затем их контейнеры и тома удаляются.
Результаты проверок: [TELEGRAM-VALIDATION.md](TELEGRAM-VALIDATION.md).
